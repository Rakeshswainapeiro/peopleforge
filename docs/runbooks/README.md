# Runbooks

Operational procedures for on-call and DevOps. Each runbook: symptom, impact, diagnosis steps, fix, escalation.

Planned with the features that need them:

- Database restore and point-in-time recovery (with ADR-002)
- Rotating secrets (with the secrets manager, A6)
- Dead-letter queue triage (with the worker, R1-13)
- Anomaly-engine backfill (with R2-10)

For deployment, health checks and troubleshooting see [DEPLOYMENT.md](../../DEPLOYMENT.md).
